# Curiositora — Reinventing Autonomous Technical Learning

## The Core Problem
Most online technical curriculums are passive video streams or static documentation. When learners encounter complex algorithmic or architectural blockers, they lose momentum context-switching across forums. Curiositora was built to transform static lessons into interactive, continuous dialogue with personalized feedback loops.

## Technical Architecture
- **Next.js 15 App Router & React 19:** Server Components for zero-bundle initial loads, streaming SSR, and optimistic UI transitions for quiz completions.
- **Supabase & Postgres RLS:** Distributed schema with Row Level Security isolating student workspaces and tracking concept confidence scores.
- **Sub-200ms Inference Pipeline:** Orchestrated on Groq's high-speed inference engine, delivering streaming conceptual breakdowns without sluggish spinners.

## Product Engineering Takeaways
Over 80% of student feedback praised the conversational explanations over traditional static answer keys. Architecting the caching layer around Supabase pgvector allowed instant retrieval of foundational prerequisite material.
